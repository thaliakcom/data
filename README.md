## What is this repository?

These are the data files for [thaliak.com](https://thaliak.com). All data files
are composed in YAML, to make them both easy to read and write.

For more information on how to read or contribute to the repository, see [the wiki](https://github.com/thaliakcom/data/wiki/).

## AI Use

AI in this repository is **exclusively** used for the following purposes:

- Proofreading timelines
- Generating base diagrams from mechanical descriptions or other diagrams (but these
  cannot be committed as-is and still require extensive user work before publishing)

AI **must not** be and **has never** been used for any of the following purposes:

- Generating timelines
- Composing action or status effect descriptions or strategies

Any timeline where most of the text has clearly been written by AI will be
rejected outright.
